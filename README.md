# Diffusion Coefficient

<p>
  This repository contains a programming exercise on the estimation of
  <strong>diffusion coefficients</strong> from financial time series.
  It uses historical data from the <strong>S&amp;P 500</strong> and
  <strong>Nikkei 225</strong> indices to explore random walks,
  stochastic processes, and Bayesian inference.
</p>
